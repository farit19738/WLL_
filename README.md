# Отчёт по абонентам WLL 450 (Ука, RAC ВК ОДТ) — 06.05.2026

- **Report_numbers_CDMA_final.xlsx** — итоговый отчёт: количество зарегистрированных абонентов по секторам БС (лист «Ука 450», колонка F) и разбивка по PN-диапазонам РУТов (колонки G:BX). Всего 721 абонент.

## Как получить прямую ссылку на файл

1. Загрузите оба файла в свой репозиторий на GitHub (через веб-интерфейс: **Add file → Upload files**).
2. После коммита откройте файл в репозитории и нажмите **Raw** (или **Download**) — это и есть прямая ссылка на файл вида:
   `https://raw.githubusercontent.com/<пользователь>/<репозиторий>/<ветка>/<файл>`
